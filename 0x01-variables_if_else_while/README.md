# 0x01. C - Variables, if, else, while

## Description

This project focuses on using variables, conditional statements, and loops in C programming.

The tasks demonstrate how to use `if`, `else`, and `while` statements to control program execution and perform repetitive operations.
The project also introduces working with characters and numbers using the `putchar` function.

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`
* Compiled on Ubuntu using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89

* All files end with a new line
* Code follows the Betty coding style
* Output is produced using `putchar` where required

## Files

| File                       | Description                                            |
| -------------------------- | ------------------------------------------------------ |
| `0-positive_or_negative.c` | Prints whether a number is positive, negative, or zero |
| `1-last_digit.c`           | Prints the last digit of a randomly generated number   |
| `2-print_alphabet.c`       | Prints the alphabet in lowercase                       |
| `3-print_alphabets.c`      | Prints the alphabet in lowercase and uppercase         |
| `4-print_alphabt.c`        | Prints the alphabet except `q` and `e`                 |
| `5-print_numbers.c`        | Prints numbers from 0 to 9                             |
| `6-print_numberz.c`        | Prints numbers from 0 to 9 using `putchar`             |
| `7-print_tebahpla.c`       | Prints the alphabet in reverse                         |
| `8-print_base16.c`         | Prints all hexadecimal numbers in lowercase            |
| `9-print_comb.c`           | Prints combinations of single-digit numbers            |
| `100-print_comb3.c`        | Prints combinations of two different digits            |
| `101-print_comb4.c`        | Prints combinations of three different digits          |
| `102-print_comb5.c`        | Prints combinations of two two-digit numbers           |
