# 0x03. C - Debugging

## Description

This project focuses on debugging C programs.
It involves identifying and fixing errors in existing code to ensure the programs run correctly and produce the expected output.

The tasks help build problem-solving skills by analyzing code behavior, understanding compiler errors, and applying fixes without rewriting entire programs.

## Learning Objectives

At the end of this project, I learned how to:

* Explain what debugging means
* Identify and fix bugs in C programs
* Read, understand and interpret compiler error messages
* Use logical reasoning to trace program execution
* Apply logical debugging using test programs with different inputs
* Improve code correctness without changing intended functionality

## Genaral Requirements

* Allowed editors: `vi`, `vim`, `emacs`
* Compiled on Ubuntu using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89

* Each file must end with a new line
* Each directory must include a README.md file
* Code follows the Betty coding style
* Do not use `printf` for debugging unless instructed
* Do not remove existing code unnecessarily use a comment instead
