# 0x00. C - Hello, World

## Description

This project introduces the basics of the C programming language and the compilation process using the GCC compiler.
It demonstrates how a C program passes through preprocessing, compilation, assembly, and linking stages.

The tasks also include simple C programs that print text and display information about data types.

## Requirements

* Allowed editors: `vi`, `vim`, `emacs`
* Compiled on Ubuntu using:

gcc -Wall -Werror -Wextra -pedantic -std=gnu89

* All files end with a new line
* Bash scripts must be executable
* Code follows the Betty coding style

## Files

| File             | Description                                                 |
| ---------------- | ----------------------------------------------------------- |
| `0-preprocessor` | Runs a C file through the preprocessor and saves the result |
| `1-compiler`     | Compiles a C file but does not link                         |
| `2-assembler`    | Generates assembly code from a C file                       |
| `3-name`         | Compiles a C file and outputs an executable named `cisfun`  |
| `4-puts.c`       | Prints a line using the `puts` function                     |
| `5-printf.c`     | Prints a line using the `printf` function                   |
| `6-size.c`       | Prints the size of various data types                       |
| `100-intel`      | Generates assembly code using Intel syntax                  |
| `101-quote.c`    | Prints a quote to the standard error stream                 |
