C - Functions, nested loops

This project contains several C programs that demonstrate the use of functions, nested loops, conditionals, and basic arithmetic operations. The programs print characters, numbers, and perform simple calculations using the C programming language.

All programs were compiled using gcc on a Linux environment and follow standard C coding practices.

Requirements

Allowed editors: vi, vim, emacs

All files compiled on Ubuntu Linux

Compiler: gcc -Wall -Werror -Wextra -pedantic -Wextra -std=gnu89

Code follows the Betty coding style

Each file ends with a new line

No use of global variables

Standard library allowed where necessary

Files and Descriptions
0-putchar.c - Prints _putchar followed by a new line using the _putchar function.

1-alphabet.c - Prints the lowercase alphabet from a to z, followed by a new line.

2-print_alphabet_x10.c - Prints the lowercase alphabet 10 times, followed by a new line each time.

3-islower.c - Checks if a character is lowercase. Returns:
1 if the character is lowercase
0 otherwise

4-isalpha.c - Checks if a character is an alphabetic character. Returns:
1 if the character is a letter
0 otherwise

5-sign.c - Prints the sign of a number. Returns:
1 if positive
0 if zero
-1 if negative

6-abs.c - Computes the absolute value of an integer.

7-print_last_digit.c - Prints the last digit of a number and returns the value of the last digit.

8-24_hours.c - Prints every minute of the day from 00:00 to 23:59.

9-times_table.c - Prints the 9 times table, starting with 0.

10-add.c - Adds two integers and returns the result.

11-print_to_98.c - Prints all natural numbers from n to 98. Numbers are separated by a comma and space.

100-times_table.c - Prints the n times table, starting with 0 and n must be between 0 and 15.

101-natural.c -Computes and prints the sum of all multiples of 3 or 5 below 1024.

102-fibonacci.c - Prints the first 50 Fibonacci numbers, starting with 1 and 2.

103-fibonacci.c - Finds and prints the sum of the even-valued Fibonacci numbers whose values do not exceed 4,000,000.

104-fibonacci.c - Prints the first 98 Fibonacci numbers, starting with 1 and 2.
This requires handling very large numbers since Fibonacci numbers grow quickly.
